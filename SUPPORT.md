# Support

## Getting help

QMD Manager provides a Windows PowerShell workflow for preparing prerequisites
and initializing Markdown collections in QMD. Before asking for help, review:

- `README.md` for requirements, usage, previews, and failure behavior.
- `docs/repository-files.md` for the file inventory.
- `CONTRIBUTING.md` for contribution expectations.
- `SECURITY.md` for security-related reports.

## Scope

Support for this repository covers:

- Using `Initialize-QmdCollection.ps1` and its supported parameters.
- Diagnosing supported Windows, PowerShell, Node.js, npm, QMD, and network
  prerequisite failures.
- Understanding previews, partial QMD state, and repository validation.
- Reporting QMD Manager documentation gaps or confusing behavior.

Support does not cover QMD internals, unsupported operating systems or
PowerShell versions, third-party service incidents, or production knowledge
content.

## Questions and issues

Use repository issues or discussions when they are enabled by the repository
owner.

Do not share secrets, tokens, passwords, private keys, or sensitive environment
values in public support requests.

## Security reports

Use `SECURITY.md` for suspected vulnerabilities or sensitive reports.
